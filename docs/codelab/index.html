From QNX Security Policy to Runtime Proof: Locking Down and Auditing a Resource Manager

Build a minimal QNX 8.0 resource manager, lock down its mount point with secpol_resmgr_attach(), prove both ALLOW (errno=0) and EACCES (errno=13) attachment, capture PID-attributed libsecpolev telemetry (dropped=0), audit a two-hop escalation chain (ivi_ui_t -> diag_helper_t -> can_hal_t), and verify remediation.

Step 0 — Preflight

Verify QNX SDP 8.0 (qcc, secpolcompile, mkifs) and qemu-system-x86_64, or run the 5-minute offline replay on committed logs (note: offline replay verifies committed artifacts and does not replace running QNX 8.0 yourself).

source ~/qnx800/qnxsdp-env.sh command -v qcc secpolcompile mkifs qemu-system-x86_64 python3 harness/verify_offline.py

Step 1 — Build

Compile codelab/starter/minimal_resmgr.c with qcc.

make -C codelab/starter minimal_resmgr

Step 2 — Policy

Compile codelab/starter/vulnerable.secpol into secpol.bin. Key primitives: type, allow_attach, pathspace, settypeid, and channel_connect.

secpolcompile -o codelab/starter/vulnerable.secpol.bin codelab/starter/vulnerable.secpol

Step 3 — Enforce

kprobe.c exercises secpol_resmgr_attach() on isolated, previously unused paths (/dev/secpol_probe_allow and /dev/secpol_probe_deny_<origin>).

KPROBE_JSON:{"origin":"audit_reader_t","op":"allow_attach","target":"/dev/secpol_probe_allow","path":"/dev/secpol_probe_allow","pid":40964,"ret":0,"outcome":"ALLOW","errno":0,"errno_name":"OK"} KPROBE_JSON:{"origin":"ivi_ui_t","op":"allow_attach","target":"/dev/secpol_probe_deny_ivi_ui_t","path":"/dev/secpol_probe_deny_ivi_ui_t","pid":16388,"ret":-1,"outcome":"DENY","errno":13,"errno_name":"EACCES"}
Check Your Answer: EACCES (13) vs. EPERM (1) vs. EEXIST (17)

EACCES (13) = policy denied allow_attach (DENY_POLICY); EPERM (1) = missing pathspace ability (DENY_ABILITY); EEXIST (17) = path already occupied (INCONCLUSIVE / PATH_COLLISION, never DENY).

Troubleshooting

  • EACCES vs. EPERM vs. EEXIST: 13 = policy denied allow_attach; 1 = missing pathspace; 17 = path collision (INCONCLUSIVE).
  • Missing SECPOL_TYPE_NAME: Required by secpol_posix_spawnattr_settypeid() when passing a string type name.
  • dropped=0 with secpolgenerate: Meaningful only in independent verification boots without secpolgenerate active.
  • libsecpolev single-consumer limit: Only one secpol_sentry instance can read /dev/name/local/_tracelog at a time.
  • QEMU TCG idle shutdown: QNX does not power off QEMU after === SECPOL_AUDIT_DONE ===; harness/run_qemu.sh treats timeout exit 124 as clean completion when the marker is present.
